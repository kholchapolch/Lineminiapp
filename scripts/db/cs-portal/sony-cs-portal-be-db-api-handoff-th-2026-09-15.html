1. Scope

สิ่งที่ BE ต้องทำ

In scope

  • สร้าง 2 CS Portal tables
  • Excel preview/apply/activate
  • Model/category/global content resolver
  • 3 APIs อ่านข้อมูลจาก DB
  • Payload validation, safe URL, tests

Out of scope

  • LIFF initialization
  • POST /api/line-session
  • LINE UUID/session flow
  • My Sony API/customer/product retrieval
  • Product warranty/serial calculation
  • Badge logic/tables

Assumption: FE หรือ existing product flow มีรายการ modelKey ของสินค้าแล้ว. API ชุดนี้คืนเฉพาะ content mapping เพื่อให้ FE merge กับ product data.

Dependency สำคัญ

ถ้า existing product response ไม่มี stable MKT Kataban/modelKey และมีเพียง free-text Model Name, mapping ยังปิดงานไม่ได้. ห้าม join ด้วยชื่อสินค้าแบบ fuzzy.

3. Schema

2 tables + existing app_config

CREATE TABLE IF NOT EXISTS cs_portal_products (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  dataset_version CHAR(64) NOT NULL,
  external_key VARCHAR(191) NULL,
  model_name VARCHAR(255) NOT NULL,
  model_key VARCHAR(191) NOT NULL,
  category_code VARCHAR(100) NULL,
  image_url VARCHAR(2048) NULL,
  sort_order INT NOT NULL DEFAULT 0,
  created_at DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  updated_at DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3)
    ON UPDATE CURRENT_TIMESTAMP(3),
  PRIMARY KEY (id),
  UNIQUE KEY uq_cs_portal_products_version_model
    (dataset_version, model_key),
  KEY idx_cs_portal_products_version_category
    (dataset_version, category_code),
  CONSTRAINT chk_cs_portal_products_sort CHECK (sort_order >= 0)
) ENGINE=InnoDB;

CREATE TABLE IF NOT EXISTS cs_portal_contents (
  id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  dataset_version CHAR(64) NOT NULL,
  external_key VARCHAR(191) NOT NULL,
  locale VARCHAR(10) NOT NULL,
  content_type VARCHAR(32) NOT NULL,
  target_type VARCHAR(32) NOT NULL,
  target_key VARCHAR(191) NOT NULL,
  action_key VARCHAR(100) NULL,
  sort_order INT NOT NULL DEFAULT 0,
  published_at DATETIME(3) NULL,
  payload JSON NOT NULL,
  created_at DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  updated_at DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3)
    ON UPDATE CURRENT_TIMESTAMP(3),
  PRIMARY KEY (id),
  UNIQUE KEY uq_cs_portal_content_version_locale_type_key
    (dataset_version, locale, content_type, external_key),
  KEY idx_cs_portal_content_lookup
    (dataset_version, locale, content_type, target_type, target_key, action_key),
  KEY idx_cs_portal_content_order
    (dataset_version, locale, content_type, target_key, published_at, sort_order),
  CONSTRAINT chk_cs_portal_content_locale CHECK (locale IN ('th','en')),
  CONSTRAINT chk_cs_portal_content_type
    CHECK (content_type IN ('cta','article','carousel','page','footer_link')),
  CONSTRAINT chk_cs_portal_target_type
    CHECK (target_type IN ('model','category','global')),
  CONSTRAINT chk_cs_portal_content_sort CHECK (sort_order >= 0)
) ENGINE=InnoDB;
app_config.cs_portal_active_dataset_version = <workbook SHA-256>
app_config.cs_portal_schema_version = 1

cs_portal_products เป็น mapping catalog ไม่ใช่ customer product table. ห้ามเก็บ LINE UUID, customer ID, serial หรือ warranty.

Target resolution

model → category → global

model:    target_key = WF-1000XM5
category: target_key = HEADPHONES
global:   target_key = PRODUCT_CENTER

Category ยังไม่พร้อม

เปิด category fallback ได้เมื่อ Product Master มี MKT Kataban → category_code หรือมี authoritative category source. ระหว่างนี้ resolver ใช้ model → global. Category rows ต้อง import fail ไม่ใช่เดา category จาก model name.

5. API — Product Content

GET /api/cs-portal/content

Query contract

GET /api/cs-portal/content
  ?locale=th
  &modelKey=WF-1000XM5
  &modelKey=XR-75X91L

locale    required: th | en
modelKey  optional repeated parameter; maximum 50 unique values
body      none

ไม่ส่ง modelKey ได้ เพื่อโหลด global footer สำหรับ No Product state. FE ต้องส่ง stable model key จาก existing product flow.

Response

{
  "locale": "th",
  "models": [{
    "requestedModelKey": "WF-1000XM5",
    "modelKey": "WF-1000XM5",
    "matchedCatalog": true,
    "categoryCode": null,
    "fallbackImageUrl": "https://approved-host/product.jpg",
    "ctas": [{
      "key": "cta-firmware",
      "label": "Check Firmware",
      "enabled": true,
      "iconUrl": null,
      "kind": "article_list",
      "actionKey": "firmware"
    }],
    "carouselItems": []
  }],
  "footerActions": []
}

DB query

SELECT value FROM app_config
WHERE `key` = 'cs_portal_active_dataset_version';

SELECT model_key, category_code, image_url
FROM cs_portal_products
WHERE dataset_version = ? AND model_key IN (?, ...);

SELECT external_key, content_type, target_type, target_key,
       action_key, sort_order, payload
FROM cs_portal_contents
WHERE dataset_version = ? AND locale = ?
  AND content_type IN ('cta','carousel','footer_link')
  AND (
    (target_type = 'model' AND target_key IN (?, ...))
    OR (target_type = 'category' AND target_key IN (?, ...))
    OR (target_type = 'global' AND target_key IN ('PRODUCT_CENTER','PRODUCT_CENTER_FOOTER'))
  );

Rules

  • Normalize/dedupe model keys; preserve first input order
  • Unknown model ยังคืน entry พร้อม matchedCatalog=false และ empty content
  • CTA ใช้ highest target precedence ต่อ action_key
  • Different action keys แสดงพร้อมกันตาม sort_order
  • All SQL values parameterized

6. API — Articles

GET /api/cs-portal/articles

Query contract

GET /api/cs-portal/articles
  ?locale=th
  &modelKey=WF-1000XM5
  &actionKey=firmware

locale     required: th | en
modelKey   required: value returned/used by /content
actionKey  required: value returned inside CTA

Response

{
  "modelKey": "WF-1000XM5",
  "actionKey": "firmware",
  "items": [{
    "key": "article-firmware-01",
    "title": "อัปเดตเฟิร์มแวร์",
    "summary": "รายละเอียดโดยย่อ",
    "imageUrl": null,
    "imageAlt": null,
    "url": "https://www.sony.co.th/approved-path",
    "publishedAt": "2026-01-01T00:00:00.000Z"
  }]
}

DB query

SELECT category_code FROM cs_portal_products
WHERE dataset_version = ? AND model_key = ? LIMIT 1;

SELECT external_key, target_type, target_key,
       sort_order, published_at, payload
FROM cs_portal_contents
WHERE dataset_version = ? AND locale = ?
  AND content_type = 'article' AND action_key = ?
  AND (
    (target_type = 'model' AND target_key = ?)
    OR (target_type = 'category' AND target_key = ?)
    OR (target_type = 'global' AND target_key = 'PRODUCT_CENTER')
  )
ORDER BY published_at DESC, sort_order ASC, external_key ASC;

ถ้าไม่มี category ให้ตัด category condition. ไม่มี article คืน 200 { items: [] }.

7. API — Register Product Page

GET /api/cs-portal/pages/register-product

Query contract

GET /api/cs-portal/pages/register-product?locale=th

locale required: th | en
body   none

Response

{
  "key": "register-product",
  "locale": "th",
  "title": "Register Product",
  "lead": "Membership benefits",
  "blocks": [
    { "type": "heading", "text": "สิทธิประโยชน์" },
    { "type": "check_list", "items": ["Benefit 1", "Benefit 2"] },
    { "type": "link_button", "label": "Register Now", "url": "https://approved-host/register" }
  ]
}

DB query

SELECT external_key, payload
FROM cs_portal_contents
WHERE dataset_version = ? AND locale = ?
  AND content_type = 'page'
  AND target_type = 'global'
  AND target_key = 'REGISTER_PRODUCT'
  AND external_key = 'register-product'
LIMIT 1;

ไม่มี page ของ locale นี้คืน 404. ไม่ fallback ข้ามภาษา. Payload invalid คืน safe 500.

   |-- preview -->|-- map/validate -->|                       |                      |
   |<-- report; no DB write ----------|                       |                      |
   |-- apply ---->|-- validate all --->|-- transaction insert>|                      |
