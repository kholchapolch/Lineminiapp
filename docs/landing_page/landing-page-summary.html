LP-01 · My Badges (บ้านแคมเปญ)

เส้นทาง: /{locale}/my-badges

บล็อกเนื้อหา สิ่งที่แสดง เงื่อนไข
โปรไฟล์ ชื่อและรูปจาก LIFF ถ้ามี ไม่เช่นนั้นตัวอักษรแรกของชื่อ มี line session หรือข้อมูล API
สถิติ ได้/ทั้งหมด ของเหรียญผลิตภัณฑ์ และเหรียญภารกิจ (นับชั้นที่ achieved) หลังโหลดข้อมูลสำเร็จ
เหรียญผลิตภัณฑ์ของฉัน พรีวิวสูงสุด 3 การ์ดล่าสุด หรือข้อความว่างให้ลงทะเบียนสินค้า ว่างเมื่อไม่มีสินค้าที่ปลดล็อกในพรีวิว
เหรียญภารกิจของฉัน พรีวิวสูงสุด 3 ชั้นที่ได้แล้ว หรือข้อความว่างชุดเดียวกัน ว่างเมื่อยังไม่ได้ชั้นใด
Call to Action
ปุ่ม ข้อความ เงื่อนไขแสดง / กดได้ ปลายทาง
ดูทั้งหมด (สินค้า) ดูทั้งหมด (See all) แสดงเสมอเมื่อ interactive (รวมวิวว่างหลัง error) /{locale}/my-products
ดูทั้งหมด (ภารกิจ) ดูทั้งหมด (See all) เช่นเดียวกับด้านบน /{locale}/my-missions
การ์ดสินค้าในพรีวิว รูป + ชื่อรุ่น มีรายการในพรีวิว รายละเอียดสินค้า
การ์ดภารกิจในพรีวิว รูปชั้นที่ได้ มีชั้นที่ achieved รายละเอียดชั้นนั้น
หน้าแรก หน้าแรก (Home) แถบล่าง ไฮไลต์หน้านี้ บ้านเดียวกัน
ลงทะเบียนสินค้า ลงทะเบียนสินค้า (Register Products) มี href เมื่อตั้ง NEXT_PUBLIC_ACCOUNT_URL เว็บ Sony ภายนอก
คำถามที่พบบ่อย คำถามที่พบบ่อย (FAQ) แสดงเสมอ microsite digital-badge (hardcode)

LP-02–05 · แคตตาล็อกและรายละเอียด

หน้า เนื้อหาหลัก CTA เงื่อนไข
My Products หัวข้อเหรียญผลิตภัณฑ์ของฉัน + คำอธิบายให้ซื้อ/ลงทะเบียนเลนส์ที่ร่วมรายการ + ตัวกรองกลุ่ม ตัวกรอง · การ์ดที่ปลดล็อก · กลับหน้าหลัก การ์ดล็อกไม่มีลิงก์ ไม่มีรูป
Product detail แชร์เหรียญผลิตภัณฑ์ · ชื่อเหรียญ · ปลดล็อคเมื่อ · จำนวนที่มี แชร์ (Share) · กลับหน้าหลัก เข้าได้เมื่อ API คืนสินค้าที่ปลดล็อก ไม่มีซีเรียลบนจอแม้มีในข้อมูล
My Missions หัวข้อเหรียญภารกิจ + คำอธิบายเดียวกันแบบสินค้า + แปดส่วน Quest พร้อมคำอธิบายสะสมรุ่น โหนดชั้น (กดได้ทุกชั้น) · กลับหน้าหลัก โหนดแสดง progress/target
Mission ยังไม่ครบ ชื่อ Quest · คำอธิบาย · ความคืบหน้า · รายการตั๋วรุ่น ลงทะเบียนสินค้า (ถ้ามี URL) · รายละเอียด (See More) บนตั๋ว pending ที่มี productUrl · ย้อนกลับไป My Missions progress < target · ตั๋ว completed แสดงป้ายสำเร็จ ไม่มีลิงก์
Mission ครบชั้น แชร์เหรียญภารกิจ · เหรียญภารกิจที่ได้รับ · วันที่ถ้ามี แชร์ · กลับหน้าหลัก progress ≥ target · ไม่มีรายการตั๋วในเลย์เอาต์นี้

LP-06 · หน้าเข้า โหลด และบล็อก

หน้า เนื้อหา CTA เงื่อนไข
/{locale}/badges production กำลังโหลดข้อมูลเหรียญตรา / ไม่สามารถเข้าถึงได้ + ข้อความแหล่งแคมเปญที่อนุมัติ ไม่มีปุ่ม — สำเร็จแล้ว replace ไปบ้าน มี entryError หรือ LIFF ล้ม → ค้างข้อความบล็อก
/{locale}/entry ไม่มี UI (redirect อย่างเดียว) — ดูเอกสาร redirect
PageLoading โครงกระดูกตามหน้า ไม่มีข้อความ CTA — session กำลังโหลด หรือยังไม่มี data
PageError ไม่สามารถเข้าถึงได้ + ข้อความ error ไม่มีปุ่มลองใหม่ เฉพาะรายละเอียดสินค้าเมื่อ API ไม่ 2xx
ไม่มีหน้า “สมัครสมาชิก Sony” ใน Mini App CTA สมาชิกคือลงทะเบียนสินค้าภายนอก

LP-07 · หน้าแชร์สำหรับ Facebook

/{locale}/share/product/{id} และ /{locale}/share/mission/{id}

  • หัวข้อ: เหรียญของฉันจาก Sony (My badges from Sony)
  • คำโปรย: มาดูเหรียญที่ฉันปลดล็อกได้ในแคมเปญนี้!
  • รูปเหรียญถ้ามีในกฎ
  • ไม่มีปุ่ม CTA ในหน้า — ใช้เป็น OG สำหรับ crawler
  • เงื่อนไข: รหัสต้องตรงกฎ ไม่เช่นนั้น notFound

ภาพรวมช่องทางเข้า

LINE Official Account / rich menu / แชท
        │  (ลิงก์ที่ตั้งใน LINE Developers — ไม่ได้อยู่ในรีโป)
        ▼
LIFF / Mini App URL  (HTTPS + LIFF ID)
        │
        ▼
Next.js middleware  ปรับ path เก่าและใส่ locale เริ่มต้น th
        │
        ├── / หรือ /badge หรือ /my-badges  →  /th/my-badges
        ├── /entry                         →  /th/entry
        └── /{locale}/...                  →  ไปหน้าตาม path

/{locale}/entry  (ถ้าใช้)
        ├── origin/referrer ไม่ผ่าน     →  /{locale}/badges?entryError=missing-source|blocked-source
        ├── ไม่มีคุกกี้เซสชัน           →  /{locale}/badges?entryError=missingLineSession
        └── มีเซสชัน                    →  /{locale}/badges

/{locale}/badges  (landing ทางเทคนิค)
        ├── local + mock + ?mock=1&sku=  →  /api/mock-session → /{locale}/my-badges + คุกกี้
        ├── APP_ENV=local และ Sony mock  →  redirect ตรง /{locale}/my-badges
        ├── production (line-session)    →  LIFF Login (ID token) → replace /{locale}/my-badges
        └── ?debug=1                     →  หน้าวินิจฉัย BadgeClient

Login = LINE LIFF getIDToken → POST /api/line-session → คุกกี้ sony_line_session
ไม่ได้ login อีเมล/รหัส Sony
