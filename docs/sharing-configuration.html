Sharing Configuration Document

Open Graph, Share URL, Redirect URL, Domain และ Environment ที่เกี่ยวข้อง ไม่ใส่ secret

Environment

ตัวแปร บทบาทต่อการแชร์
NEXT_PUBLIC_APP_BASE_URL origin ที่ไคลเอนต์ใช้ประกอบ URL รูป ต้อง HTTPS บน staging/production และตรง APP_BASE_URL
APP_BASE_URL origin ฝั่งเซิร์ฟเวอร์สำหรับ OG metadataBase และ og:url
NEXT_PUBLIC_LIFF_ID liff.openWindow เมื่อไม่มี Web Share หรือ Web Share ใช้ไม่ได้

ไฟล์สาธารณะรูปเหรียญอยู่ภายใต้ /product-badge/ และ /quest-badge/ (หรือ URL เต็มถ้ากฎเก็บ absolute เช่น blob storage)

Domain

  • แอป Mini App / OG: โฮสต์ใน APP_BASE_URL (placeholder https://<public-host>)
  • Facebook: www.facebook.com (sharer) — ต้องอนุญาตเปิดหน้าต่างภายนอกจาก LIFF
  • ถ้าเก็ปรูปนอกแอป: origin ของ CDN/blob ตามค่าในฐานข้อมูล
ไม่มี Facebook App ID, redirect_uri ของ Facebook Login หรือ OAuth ในโปรเจกต์นี้ “Redirect” ของแชร์คือการเปิด sharer หรือ share sheet ไม่มีการกลับ callback เข้าแอป

Share URL

ชนิด รูปแบบ ใครใช้
Asset (ปุ่มในแอป) {APP_BASE}/product-badge/{MODEL}.png หรือ quest-badge FacebookShareAction
Facebook sharer https://www.facebook.com/sharer/sharer.php?u={encoded-asset} openWindow / window.open
OG หน้าสินค้า /{locale}/share/product/{productRuleCode} crawler / เปิดตรง
OG หน้าภารกิจ /{locale}/share/mission/{questCode}-{level} เช่น portrait-master-gold, trinity-master-achievement

Open Graph (หน้า /share/...)

og:type         website
og:title        messages.shareOg.title   (ค่าคงที่ ไม่ใช่ชื่อรุ่น)
og:description  messages.shareOg.description
og:url          absolute ของ pagePath
og:image        shareImageUrl หรือ achievedImageUrl ของกฎ/ชั้น
twitter:card    summary_large_image
image type      image/png เมื่อนามสกุล .png

ถ้าไม่พบกฎ: metadata ยังมี title/description ของแคมเปญ แต่หน้าเรนเดอร์เป็น notFound

ต้องให้ Facebook crawler เข้าถึงรูปและหน้า OG ได้โดยไม่ต้อง LIFF โฮสต์ต้อง HTTPS ตามสเปก deploy
