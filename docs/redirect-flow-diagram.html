Redirect Flow Diagram

เส้นทางจาก URL, LINE OA, Landing Page, Login, LIFF และ Error Page

แอปนี้ไม่มี webhook LINE OA OA / rich menu ถ้าใช้ จะชี้ URL Mini App ภายนอกโค้ดนี้

ภาพรวมช่องทางเข้า

LINE Official Account / rich menu / แชท
        │  (ลิงก์ที่ตั้งใน LINE Developers — ไม่ได้อยู่ในรีโป)
        ▼
LIFF / Mini App URL  (HTTPS + LIFF ID)
        │
        ▼
Next.js middleware  ปรับ path เก่าและใส่ locale เริ่มต้น th
        │
        ├── / หรือ /badge หรือ /my-badges  →  /th/my-badges
        ├── /entry                         →  /th/entry
        └── /{locale}/...                  →  ไปหน้าตาม path

/{locale}/entry  (ถ้าใช้)
        ├── origin/referrer ไม่ผ่าน     →  /{locale}/badges?entryError=missing-source|blocked-source
        ├── ไม่มีคุกกี้เซสชัน           →  /{locale}/badges?entryError=missingLineSession
        └── มีเซสชัน                    →  /{locale}/badges

/{locale}/badges  (landing ทางเทคนิค)
        ├── local + mock + ?mock=1&sku=  →  /api/mock-session → /{locale}/my-badges + คุกกี้
        ├── APP_ENV=local และ Sony mock  →  redirect ตรง /{locale}/my-badges
        ├── production (line-session)    →  LIFF Login (ID token) → replace /{locale}/my-badges
        └── ?debug=1                     →  หน้าวินิจฉัย BadgeClient

Login = LINE LIFF getIDToken → POST /api/line-session → คุกกี้ sony_line_session
ไม่ได้ login อีเมล/รหัส Sony

หลังเข้าบ้าน (ไม่ redirect เซิร์ฟเวอร์)

/{locale}/my-badges
  ดูทั้งหมดสินค้า     →  /{locale}/my-products          (Link)
  การ์ดสินค้า         →  /{locale}/my-product/{id}
  ดูทั้งหมดภารกิจ     →  /{locale}/my-missions
  การ์ด/โหนดชั้น     →  /{locale}/my-missions/{tierId}
  Register แถบล่าง    →  NEXT_PUBLIC_ACCOUNT_URL         (ออกโดเมน)
  FAQ                 →  sony.co.th microsite            (ออกโดเมน)
  แชร์เหรียญ          →  Facebook / share sheet          (ไม่ redirect ในแอป)

Deep link กลับภารกิจ (สร้างแล้วไม่ได้ต่อ query ลงทะเบียน)
  https://miniapp.line.me/{liffId}/th/my-missions/{id}

Error Page

LIFF / entryError บน /badges
  → แผง "ไม่สามารถเข้าถึงได้" (BadgeSessionBootstrap)  ไม่เด้งไปบ้าน

รายละเอียดสินค้า API 404/500
  → PageError แผงเดียวกัน  ค้างที่ URL รายละเอียด

รหัส share ไม่ตรงกฎ หรือ locale หน้าไม่ใช่ th|en
  → Next.js notFound()

Sony ไม่พร้อม บน my-products / my-missions
  → ไม่ใช่หน้า error แยก: HTTP 200 แคตตาล็อกล็อก หรือค้าง skeleton

/api/health ล้ม / โฮสต์ล่ม
  → หน้าเว็บไม่ขึ้น (แพลตฟอร์ม) ไม่มี custom error HTML ในแอป
src/app/page.tsx redirect ไป /th/badges แต่ middleware จับ / ไป /th/my-badges ก่อน ผู้ใช้ที่เปิดโดเมนรากจึงไม่ผ่านหน้า badges
