Deployment Record

Version, Commit/Build, วันที่ Deploy, ผู้ดำเนินการ และผลตรวจสอบ

Git ไม่เก็บประวัติ deploy ที่กรอกแล้ว แถวด้านล่างเป็นแม่แบบและค่าที่อ่านได้จากรีโปเท่านั้น อย่าใส่ secret

เวอร์ชันที่ระบุในโค้ด (ไม่ใช่ใบรับรองว่าอยู่บนเซิร์ฟเวอร์แล้ว)

ชนิด ค่าในรีโป หมายเหตุ
แพ็กเกจ npm package.json → 0.1.0 ไม่ถูกเขียนบนหน้าเว็บหรือ health endpoint
กฎเหรียญ (seed) badge_rules_version = 2026-07-24-product-urls-001 ตรวจบนฐานหลัง seed ไม่ได้อยู่ใน artifact แอปโดยอัตโนมัติ
Node ที่ CI ใช้ 24.x workflow UAT
Next.js (lockfile) ตาม package-lock.json (^14.2.23 ใน package.json) —

ที่ไปดู Commit / Build จริง

  • GitHub Actions: workflow “Deploy Next.js UAT site” environment uat
  • SHA ของงาน = commit ที่ checkout
  • Artifact ชื่อ nextjs-production-server
  • Azure Deployment Center / ประวัติ App Service mysonybadgestg
ทริกเกอร์ใน YAML คือสาขา dev และ workflow_dispatch ไม่มีฟิลด์ “ผู้ดำเนินการ” ในแอป — เป็นผู้กด dispatch หรือบัญชีที่ push

แม่แบบบันทึกต่อครั้ง (กรอกนอก Git หรือวิกิภายใน)

คัดลอกแถวว่างไปกรอกหลัง deploy — ตัวอย่างไม่ใช่ผล UAT ที่ยืนยันแล้ว
ฟิลด์ วิธีเติม ตัวอย่างรูปแบบ (ไม่มีค่าจริง)
สภาพแวดล้อม UAT / Production UAT (APP_ENV=staging)
วันที่–เวลา deploy จาก Actions หรือ Azure (เขตเวลาที่ตกลง) —
ผู้ดำเนินการ ผู้ push / ผู้อนุมัติ environment / ผู้รัน DB —
Git commit SHA หัวงาน Actions <40-char-sha>
สาขา ตามทริกเกอร์ dev หรือ SHA ที่ dispatch
ผล CI (build job) config:check, seed SQL check, test, lint, build Pass / ไม่ผ่าน + ลิงก์ run
ผล deploy job webapps-deploy สำเร็จหรือไม่ Pass / ไม่ผ่าน
ผลตรวจสอบ HTTP /, /api/health, /deployment-check.html 2xx + ข้อความตามสเปก หรือ Warning: 403 x-ms-forbidden-ip
DB รอบนี้ migrate/seed หรือไม่ SHA + badge_rules_version บนฐาน ไม่รัน / รันชุด prod / รันชุด default
หมายเหตุ Sony mode mock/live โดยไม่ใส่คีย์ —

ผลตรวจสอบมาตรฐานเมื่อ IP ถูกอนุญาต

  • GET /api/health → JSON มี "status":"ok" และ "runtime":"nodejs"
  • /deployment-check.html มี Deployment smoke test passed.
  • รากโดเมนตอบ 2xx หลังตาม redirect

Health ไม่คืนเวอร์ชันแอปหรือ commit ต้องผูก SHA จากระบบ deploy เอง
