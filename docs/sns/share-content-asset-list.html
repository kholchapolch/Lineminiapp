ข้อความตามสถานะ

สถานะ UI มีปุ่มแชร์? Caption จากแอป ข้อความบนจอ
สินค้า locked ไม่มี (เข้าหน้ารายละเอียดไม่ได้) — การ์ดไม่มีรูปในแคตตาล็อก
สินค้า unlocked มี ไม่ส่ง caption แชร์เหรียญผลิตภัณฑ์ · เหรียญผลิตภัณฑ์ที่ได้รับ · ชื่อรุ่น · ปลดล็อคเมื่อ · จำนวนที่มี
ภารกิจชั้นยังไม่ครบ ไม่มี — ความคืบหน้า และตั๋วรุ่น
ภารกิจชั้นครบ มี ไม่ส่ง caption แชร์เหรียญภารกิจ · เหรียญภารกิจที่ได้รับ · วันที่ถ้ามี
หน้า OG /share ไม่มีปุ่ม og:title / og:description คงที่ของแคมเปญ (ไม่เปลี่ยนตามชื่อรุ่น) หัวข้อและคำโปรยเดียวกัน + รูป
ปุ่ม disabled แสดงแต่กดไม่ได้ — สร้าง URL รูปไม่ได้ หรือกำลังแชร์อยู่
Thumbnail บน Facebook เมื่อแชร์ URL รูปโดยตรง ขึ้นกับว่า Facebook ดึงไฟล์ PNG ได้หรือไม่ ไม่ได้ส่ง og:title คู่กับ URL รูป Preview เต็มตามสเปก OG เกิดเมื่อแชร์ URL หน้า /share/... ซึ่งปุ่มหลักไม่ได้ใช้
