Social Sharing Specification

ช่องทางที่รองรับ

ช่องทาง สถานะ วิธีเรียกจากแอป
Facebook รองรับ — ปุ่มเดียวใน UI ป้าย แชร์ (Share) + ไอคอน Facebook · ลำดับ: Web Share sheet (ผู้ใช้เลือก Facebook) → liff.openWindow ไป facebook.com/sharer → window.open
LINE แชท / X / Instagram ไม่มีปุ่มเฉพาะ ถ้าอุปกรณ์มี navigator.share ผู้ใช้อาจเลือกแอปอื่นในระบบ แอปส่งแค่ URL ไม่บังคับแอปปลายทาง

จุดกด: รายละเอียดสินค้าที่ปลดล็อก และหน้ารายละเอียดภารกิจเมื่อชั้นนั้นครบแล้วเท่านั้น

สิ่งที่ถูกส่งตอนกดแชร์ใน Mini App

ปุ่มแชร์ส่ง URL ของไฟล์รูปเหรียญ ไม่ใช่ URL หน้า Mini App และไม่ใช่หน้า /share/... navigator.share({ url }) ไม่ส่ง title, text, ไฟล์ หรือ hashtag คอมโพเนนต์มี props hashtag แต่หน้าเรียกไม่ส่งค่า
องค์ประกอบ ค่าที่ใช้จริง
ข้อความ / caption จากแอป ไม่มี — Facebook หรือ share sheet กำหนดเอง ยกเว้นหน้า OG ถ้า crawler เปิดหน้า share
รูป Product: shareImageUrl ของ threshold (seed = รูป achieved) Quest: shareImageUrl || badgeImageUrl ของชั้นนั้น
URL รูปที่แปลงเป็น absolute ด้วย NEXT_PUBLIC_APP_BASE_URL / APP_BASE_URL path ถูก percent-encode (ห้ามเว้นวรรคดิบ)
Facebook sharer URL https://www.facebook.com/sharer/sharer.php?u= + encode พิเศษของ %20 เป็นลำดับ %252520 ใน query 
กดแชร์
  → toShareableAssetUrl(รูป)
  → ถ้ามี Web Share: navigator.share({ url: รูป }) เท่านั้น
  → ไม่มี / ล้มที่ไม่ใช่ยกเลิก: เปิด Facebook sharer ของ URL รูป
  → ผู้ใช้ยกเลิก share sheet (AbortError) = ถือว่าจัดการแล้ว ไม่เปิด Facebook ซ้ำ

หน้า OG (ไม่ได้อยู่ในปุ่มหลัก)

ถ้ามีคนเปิดหรือแชร์ https://<host>/{locale}/share/product/{productId} หรือ .../share/mission/{missionId} crawler จะได้ og:title / og:description คงที่จาก shareOg และ og:image เป็นรูปเหรียญ

  • title: เหรียญของฉันจาก Sony (My badges from Sony)
  • description: มาดูเหรียญที่ฉันปลดล็อกได้ในแคมเปญนี้!

Sharing Configuration Document

Open Graph, Share URL, Redirect URL, Domain และ Environment ที่เกี่ยวข้อง ไม่ใส่ secret

  • Environment

Environment

ตัวแปร บทบาทต่อการแชร์
NEXT_PUBLIC_APP_BASE_URL origin ที่ไคลเอนต์ใช้ประกอบ URL รูป ต้อง HTTPS บน staging/production และตรง APP_BASE_URL
APP_BASE_URL origin ฝั่งเซิร์ฟเวอร์สำหรับ OG metadataBase และ og:url
NEXT_PUBLIC_LIFF_ID liff.openWindow เมื่อไม่มี Web Share หรือ Web Share ใช้ไม่ได้

ไฟล์สาธารณะรูปเหรียญอยู่ภายใต้ /product-badge/ และ /quest-badge/ (หรือ URL เต็มถ้ากฎเก็บ absolute เช่น blob storage)

Domain

  • แอป Mini App / OG: โฮสต์ใน APP_BASE_URL (placeholder https://<public-host>)
  • Facebook: www.facebook.com (sharer) — ต้องอนุญาตเปิดหน้าต่างภายนอกจาก LIFF
  • ถ้าเก็ปรูปนอกแอป: origin ของ CDN/blob ตามค่าในฐานข้อมูล
ไม่มี Facebook App ID, redirect_uri ของ Facebook Login หรือ OAuth ในโปรเจกต์นี้ “Redirect” ของแชร์คือการเปิด sharer หรือ share sheet ไม่มีการกลับ callback เข้าแอป

Share URL

ชนิด รูปแบบ ใครใช้
Asset (ปุ่มในแอป) {APP_BASE}/product-badge/{MODEL}.png หรือ quest-badge FacebookShareAction
Facebook sharer https://www.facebook.com/sharer/sharer.php?u={encoded-asset} openWindow / window.open
OG หน้าสินค้า /{locale}/share/product/{productRuleCode} crawler / เปิดตรง
OG หน้าภารกิจ /{locale}/share/mission/{questCode}-{level} เช่น portrait-master-gold, trinity-master-achievement

Open Graph (หน้า /share/...)

og:type         website
og:title        messages.shareOg.title   (ค่าคงที่ ไม่ใช่ชื่อรุ่น)
og:description  messages.shareOg.description
og:url          absolute ของ pagePath
og:image        shareImageUrl หรือ achievedImageUrl ของกฎ/ชั้น
twitter:card    summary_large_image
image type      image/png เมื่อนามสกุล .png

ถ้าไม่พบกฎ: metadata ยังมี title/description ของแคมเปญ แต่หน้าเรนเดอร์เป็น notFound

ต้องให้ Facebook crawler เข้าถึงรูปและหน้า OG ได้โดยไม่ต้อง LIFF โฮสต์ต้อง HTTPS ตามสเปก deploy

ข้อความตามสถานะ

สถานะ UI มีปุ่มแชร์? Caption จากแอป ข้อความบนจอ
สินค้า locked ไม่มี (เข้าหน้ารายละเอียดไม่ได้) — การ์ดไม่มีรูปในแคตตาล็อก
สินค้า unlocked มี ไม่ส่ง caption แชร์เหรียญผลิตภัณฑ์ · เหรียญผลิตภัณฑ์ที่ได้รับ · ชื่อรุ่น · ปลดล็อคเมื่อ · จำนวนที่มี
ภารกิจชั้นยังไม่ครบ ไม่มี — ความคืบหน้า และตั๋วรุ่น
ภารกิจชั้นครบ มี ไม่ส่ง caption แชร์เหรียญภารกิจ · เหรียญภารกิจที่ได้รับ · วันที่ถ้ามี
หน้า OG /share ไม่มีปุ่ม og:title / og:description คงที่ของแคมเปญ (ไม่เปลี่ยนตามชื่อรุ่น) หัวข้อและคำโปรยเดียวกัน + รูป
ปุ่ม disabled แสดงแต่กดไม่ได้ — สร้าง URL รูปไม่ได้ หรือกำลังแชร์อยู่
Thumbnail บน Facebook เมื่อแชร์ URL รูปโดยตรง ขึ้นกับว่า Facebook ดึงไฟล์ PNG ได้หรือไม่ ไม่ได้ส่ง og:title คู่กับ URL รูป Preview เต็มตามสเปก OG เกิดเมื่อแชร์ URL หน้า /share/... ซึ่งปุ่มหลักไม่ได้ใช้
