Social Sharing Specification

ช่องทางที่รองรับ (Facebook) พร้อมข้อความ รูปภาพ และ URL ที่แชร์

ช่องทางที่รองรับ

ช่องทาง สถานะ วิธีเรียกจากแอป
Facebook รองรับ — ปุ่มเดียวใน UI ป้าย แชร์ (Share) + ไอคอน Facebook · ลำดับ: Web Share sheet (ผู้ใช้เลือก Facebook) → liff.openWindow ไป facebook.com/sharer → window.open
LINE แชท / X / Instagram ไม่มีปุ่มเฉพาะ ถ้าอุปกรณ์มี navigator.share ผู้ใช้อาจเลือกแอปอื่นในระบบ แอปส่งแค่ URL ไม่บังคับแอปปลายทาง

จุดกด: รายละเอียดสินค้าที่ปลดล็อก และหน้ารายละเอียดภารกิจเมื่อชั้นนั้นครบแล้วเท่านั้น

สิ่งที่ถูกส่งตอนกดแชร์ใน Mini App

ปุ่มแชร์ส่ง URL ของไฟล์รูปเหรียญ ไม่ใช่ URL หน้า Mini App และไม่ใช่หน้า /share/... navigator.share({ url }) ไม่ส่ง title, text, ไฟล์ หรือ hashtag คอมโพเนนต์มี props hashtag แต่หน้าเรียกไม่ส่งค่า
องค์ประกอบ ค่าที่ใช้จริง
ข้อความ / caption จากแอป ไม่มี — Facebook หรือ share sheet กำหนดเอง ยกเว้นหน้า OG ถ้า crawler เปิดหน้า share
รูป Product: shareImageUrl ของ threshold (seed = รูป achieved) Quest: shareImageUrl || badgeImageUrl ของชั้นนั้น
URL รูปที่แปลงเป็น absolute ด้วย NEXT_PUBLIC_APP_BASE_URL / APP_BASE_URL path ถูก percent-encode (ห้ามเว้นวรรคดิบ)
Facebook sharer URL https://www.facebook.com/sharer/sharer.php?u= + encode พิเศษของ %20 เป็นลำดับ %252520 ใน query 
กดแชร์
  → toShareableAssetUrl(รูป)
  → ถ้ามี Web Share: navigator.share({ url: รูป }) เท่านั้น
  → ไม่มี / ล้มที่ไม่ใช่ยกเลิก: เปิด Facebook sharer ของ URL รูป
  → ผู้ใช้ยกเลิก share sheet (AbortError) = ถือว่าจัดการแล้ว ไม่เปิด Facebook ซ้ำ

หน้า OG (ไม่ได้อยู่ในปุ่มหลัก)

ถ้ามีคนเปิดหรือแชร์ https://<host>/{locale}/share/product/{productId} หรือ .../share/mission/{missionId} crawler จะได้ og:title / og:description คงที่จาก shareOg และ og:image เป็นรูปเหรียญ

  • title: เหรียญของฉันจาก Sony (My badges from Sony)
  • description: มาดูเหรียญที่ฉันปลดล็อกได้ในแคมเปญนี้!
