ข้อตกลงร่วม

  • Base path คือ origin ของแอป เช่น https://stglineminiapp.sony.co.th
  • JSON ใช้ Content-Type: application/json
  • ไม่มี version prefix เช่น /v1
  • ไม่มี CORS header พิเศษ — คาดว่าเรียก same-origin จาก Mini App
  • ไคลเอนต์ Mini App ส่ง cache: "no-store" เมื่อเรียก /api/my-*

Authentication

แบบ ตำแหน่ง รายละเอียด
LINE ID token JSON body idToken เซิร์ฟเวอร์ verify กับ LINE แล้วตั้ง cookie ไม่คืน LINE ID ใน JSON
Cookie sony_line_session Header Cookie HttpOnly, SameSite=Lax, อายุ 1 ชม. ใช้กับ /entry และ /api/customer-products
Query lineuuid URL query ใช้กับ /api/my-* ในปัจจุบัน ไม่ตรวจ cookie
Mini App ส่ง LINE user ID ใน query ของ XHR นี่คือสัญญาที่ใช้จริง ไม่ใช่โมเดลที่แนะนำด้านความปลอดภัย

Error code

เมื่อล้มเหลว บอดี้เป็น JSON:

{
  "code": "UNAUTHORIZED",
  "message": "LINE session is required."
}
HTTP code message (ที่ส่งให้ไคลเอนต์) เมื่อไหร่
400 MISSING_ID_TOKEN LINE ID token is required. body ไม่มี idToken ที่เป็นสตริงไม่ว่าง
400 MISSING_SKU At least one SKU is required. mock-session ไม่มี query sku
401 UNAUTHORIZED LINE session is required. (หรือข้อความ verify ไม่ผ่าน) ไม่มี/คุกกี้ไม่ถูกต้อง, token หมดอายุ, aud ไม่ตรง
404 NOT_FOUND Not found. / Product badge not found. / Mission badge not found. mock-session นอก local; สินค้า/ภารกิจไม่มีหรือยังไม่ปลดล็อก
404 CUSTOMER_NOT_FOUND Customer profile was not found. Sony APIM คืน 404 — ใช้บน /api/customer-products
500 SONY_PRODUCT_API_ERROR Badge data is temporarily unavailable. warranty API ไม่สำเร็จหรือรูปแบบไม่ถูก
500 UNKNOWN_ERROR Something went wrong. Please try again later. ข้อผิดพลาดที่ไม่มี safeMessage

/api/my-products และ /api/my-missions เมื่อ error มักคืนชั้นล็อก 200 แทน error JSON /api/my-badges คืน error JSON ตามตาราง

รายการ ค่า

Header ไม่มีที่บังคับ
Parameter ไม่มี
Request body ไม่มี 
200

POST /api/line-session

Authentication LINE ID token ใน body (ยังไม่มี cookie ตอนเรียกครั้งแรก)
Header Content-Type: application/json 
Request
{ "idToken": "<liff.getIDToken()>" }

Response 200
Set-Cookie: sony_line_session=<payload>.<hmac>; Path=/; HttpOnly; SameSite=Lax; Max-Age=3600; Secure
{ "ok": true }

Secure ไม่ถูกใส่เมื่อ APP_ENV=local

GET /api/mock-session

ใช้ได้เฉพาะ APP_ENV=local และ SONY_PRODUCT_API_MODE=mock นอกนั้น 404

Parameter ที่อยู่ Required ความหมาย
sku query (ซ้ำได้) อย่างน้อย 1 รหัสรุ่นจำลอง
locale query ไม่ th หรือ en ค่าเริ่มต้น th

สำเร็จ: 302 ไป /{locale}/my-badges พร้อมตั้ง cookie session ของ mock LINE UUID

GET /api/customer-products

รายการ ค่า
Authentication Cookie sony_line_session บังคับ (ยกเว้น local debug+mock ที่อนุญาต query lineuuid)
Header (ไม่บังคับ) x-badge-cache-customer-key, x-badge-cache-sku-hash, x-badge-cache-rules-version — ถ้าตรงกับ metadata ปัจจุบันได้ cacheStatus: "hit"
Query debug=1 เปิด trace นอก production; lineuuid ใช้ได้เฉพาะ local mock+debug

Response ตัด PII: ไม่มี lineuuid, ไม่มีรายการสินค้าดิบ, ไม่มีซีเรียล
