Configuration Checklist

รายการ Environment Variable, Domain, Callback URL, LIFF และ API Configuration โดยไม่เปิดเผย Secret

ตรวจด้วย npm run config:check ต่อไฟล์ .env.production ค่าจริงของ UAT อยู่ใน GitHub environment secret UAT_ENV_FILE ไม่คัดลอกค่าในเอกสารนี้

Environment Variable

เครื่องหมาย: Public = ฝังในคลายเอนต์ · Server = เซิร์ฟเวอร์เท่านั้น · Secret = ห้ามใส่เอกสาร/คอมมิต
ตัวแปร ชั้น ตรวจอะไร (ไม่ใส่ค่าจริง)
APP_ENV Server UAT ใช้ staging · โปรดักชันใช้ production · ห้าม uat
APP_BASE_URL / NEXT_PUBLIC_APP_BASE_URL Server + Public HTTPS เดียวกันทั้งคู่ และอยู่ในรายการ origin/referrer
DATABASE_URL Secret โปรโตคอล mysql: ไม่มี prefix http ที่โฮสต์
DATABASE_SSL Server deploy ต้องเปิด TLS (true / ?ssl=true)
ALLOWED_ORIGINS / ALLOWED_REFERRERS Server รายการ HTTPS คั่นด้วยจุลภาค รวม origin ของแอป — ใช้กับ /entry
NEXT_PUBLIC_LIFF_ID Public ขึ้นต้นด้วย {LINE_CHANNEL_ID}- ห้ามวางค่าเต็มในวิกิสาธารณะถ้าถือเป็นรหัสช่อง
LINE_CHANNEL_ID Server ตัวเลขเท่านั้น ใช้ verify ID token
LINE_VERIFY_ID_TOKEN_URL Server ค่าเริ่มต้นในโค้ด: https://api.line.me/oauth2/v2.1/verify
APP_SESSION_SECRET / LOG_HASH_SECRET Secret ยาวอย่างน้อย 32 ตัว · HMAC คุกกี้และ hash ในปูม
NEXT_PUBLIC_DEBUG_MOCK_JSON Public deploy ต้องเป็น false
SONY_PRODUCT_API_MODE Server mock หรือ live
SONY_PRODUCT_API_BASE_URL Server URL เต็มรวม path เมื่อโหมด live
SONY_PRODUCT_API_SUBSCRIPTION_KEY Secret จำเป็นเมื่อ live · ส่งเป็นหัว Ocp-Apim-Subscription-Key
SONY_PRODUCT_API_COUNTRY_CODE Server ISO สองตัวพิมพ์เล็ก ค่าเริ่มต้นในโค้ด th
SONY_DEMO_LINE_UUID Server ตัวระบุ mock ในเครื่อง ไม่ใช้แทนเซสชันที่หายบน staging
NEXT_PUBLIC_ACCOUNT_URL Public HTTPS · ลิงก์ลงทะเบียนที่แถบล่าง
NEXT_PUBLIC_REGISTER_PRODUCT_URL Public HTTPS · ใช้ตอนภารกิจยังไม่ครบ (ไม่ต่อ query callback)
ห้ามใส่ NEXT_PUBLIC_* ให้กับรหัสผ่าน, subscription key, session secret ค่า Public ถูกฝังตอน npm run build

Domain

บทบาท ค่าที่ระบุในรีโป / ที่ต้องตั้ง
แอป UAT https://stglineminiapp.sony.co.th ต้องเท่ากับ APP_BASE_URL
App Service ชื่อ mysonybadgestg (ไม่ใช่โดเมนผู้ใช้)
LINE verify api.line.me
Sony APIM โฮสต์ใน SONY_PRODUCT_API_BASE_URL (ไม่ใส่ค่าในเอกสารนี้)
MySQL โฮสต์ใน DATABASE_URL
FAQ ใน UI https://www.sony.co.th/microsite/digital-badge/ (ฮาร์ดโค้ด)
Facebook sharer https://www.facebook.com — ไม่มีแอป Facebook OAuth ในโปรเจกต์
Production แอป ยังไม่มีโดเมนในรีโป

LIFF

  • ใน LINE Developers: สร้าง LIFF (Mini App) ให้ liffId ตรง NEXT_PUBLIC_LIFF_ID
  • Endpoint URL ในคอนโซล LINE ต้องเป็น HTTPS ของแอป เช่น https://<host>/th/my-badges (ต้องตรงโดเมนที่อนุญาต)
  • ขนาด/ประเภทตามคอนโซล LINE — โค้ดบังคับ liff.isInClient() ก่อนสร้างเซสชัน
  • Channel ID ของ Login ต้องเป็นชุดเดียวกับ LINE_CHANNEL_ID

Callback URL

ชนิด มีในแอปหรือไม่ หมายเหตุ
LINE OAuth redirect_uri ของเว็บ Login ไม่มี route รับ code ใช้ LIFF ID token → POST /api/line-session
แลกเซสชันแอป POST https://<host>/api/line-session บอดี้ { "idToken": "…" } ตั้งคุกกี้ HttpOnly
LINE Mini App deep link (สร้างในโค้ดแต่ยังไม่ส่งออก) รูปแบบ https://miniapp.line.me/{liffId}/th/my-missions/{missionId} buildRegisterProductUrl คอมเมนต์การใส่ callback จึงไม่ต่อเข้า URL ลงทะเบียนสินค้า
Facebook Login / OAuth ไม่มี —

API Configuration

API วิธีตั้ง
แอปเอง (health / my-* / line-session) origin จาก APP_BASE_URL ไม่มีคีย์แยก
LINE verify ID token LINE_VERIFY_ID_TOKEN_URL + LINE_CHANNEL_ID
Sony QueryWarrantyMySonyByLine POST ไป SONY_PRODUCT_API_BASE_URL บอดี้ countryCode + lineId โหมด mock ใช้ {APP_BASE_URL}/api/mock/sony
MySQL DATABASE_URL + TLS
