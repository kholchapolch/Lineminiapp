สรุป (Summary)

มีเทสอัตโนมัติ Navigation paths, LIFF session, landing mode, entry guard, นับสถิติบ้าน, ตั๋วภารกิจ, URL แชร์

วิธีอ่านผล Pass = Vitest ของเลเยอร์ข้อมูล/เส้นทาง Specified = พฤติกรรมในโค้ดหน้าจอที่ยังไม่รันในเบราว์เซอร์
รายงานนี้ไม่ใช่ UAT ลงนามบน iPhone/Android ใน LINE ชุด CI รัน Vitest ทั้งโปรเจกต์ ไม่มีขั้นตอน e2e หน้า Mini App

ช่องว่างและงานทดสอบที่ยังไม่มี

  • ทดสอบคอมโพเนนต์ (React Testing Library) สำหรับ BottomBar, FilterDropdown, การ์ดล็อก
  • E2E ใน LIFF หรืออย่างน้อย Playwright บน viewport 390×844: บ้าน → สินค้า → รายละเอียด → กลับ
  • ตรวจว่า error ของ my-products/my-missions ไม่ค้าง loading
  • สแนปช็อต/คู่มือ UAT บน iOS และ Android WebView
  • เทส useLineSessionData (abort, 401, ไม่มี lineuuid)
