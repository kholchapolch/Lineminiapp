ฟีเจอร์ที่ส่งมอบ

พื้นที่ สิ่งที่มีในโค้ด
LINE Mini App LIFF init, ตรวจ ID token ที่เซิร์ฟเวอร์, คุกกี้เซสชัน HttpOnly, หน้าโฮมของ user ที่ /{locale}/my-badges
เหรียญสินค้า แคตตาล็อกตามกฎใน MySQL, ปลดล็อกจากสินค้าที่ลงทะเบียนผ่าน Sony API, หน้ารายละเอียดและแชร์เมื่อปลดล็อกแล้ว
เหรียญภารกิจ ขั้น Portrait / Wide / Visionary และ achievement (Trinity, All Rounder, F2, Magnifier) พร้อมความคืบหน้าและตั๋วรุ่น
แชร์ Facebook ปุ่มแชร์รูปเหรียญ, Web Share sheet ก่อน sharer, หน้า OG ที่ /share/product|mission/…
ข้อมูล Badge Rule migrate / seed / verify, SQL ที่ generate จาก seed, ชุด default และชุด prod

รายการแก้ไข (ที่รวมในประวัติล่าสุด)

สรุปจาก commit บนสาขา ไม่ใช่รายการ ticket ภายนอก

  • แชร์ Facebook: เข้ารหัส URL ที่มีช่องว่าง, ใช้ native share sheet ก่อนเปิด sharer (iOS + แอป Facebook)
  • ลิงก์ FAQ ที่แถบล่างชี้ microsite digital-badge
  • ชื่อหัวข้อภารกิจใช้ชื่อเหรียญเมื่อมี, ปรับคำแปลไทย/อังกฤษและเลย์เอาต์มือถือ
  • เรียงเหรียญสินค้าล่าสุดตามตัวอักษรในประสบการณ์บ้าน
  • เพิ่มรูปเหรียญสินค้า SEL1224GM ในสินทรัพย์ (ชุด seed default ยังไม่มีกฎเหรียญสินค้ารุ่นนี้)
  • สคริปต์ seed/verify ชุด prod และตรวจ SQL ใน CI
  • ปรับการแสดงสถานะภาพความคืบหน้าเหรียญ

ข้อจำกัด

  • ไม่มี CMS / หน้าแอดมิน — เปลี่ยนกฎผ่าน seed ที่รีวิวแล้ว
  • ไม่มี workflow Production ในรีโป มีแค่ UAT App Service
  • หน้าต่างวันที่ของกฎใน seed เป็น null
  • ไม่มี retry / timeout บน fetch ไป Sony
  • ปุ่มแชร์ส่ง URL รูป ไม่ใช่ URL หน้า Mini App หรือหน้า OG
  • ชุด default (56 สินค้า) กับชุด prod (57 รวม SEL1224GM) คนละแคตตาล็อก แต่ใช้สตริงเวอร์ชันเดียวกัน
  • ไม่มี UI สลับภาษา — มีแค่พาธ /th/ และ /en/
  • Deploy อัตโนมัติไม่รัน migrate/seed
  • ไม่มี e2e (Playwright/Cypress) ใน CI — มี Vitest
