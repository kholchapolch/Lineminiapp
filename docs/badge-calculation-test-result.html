ยังไม่มีเทสอัตโนมัติ (Coverage gaps)

เคสเหล่านี้ระบุในสเปก/โค้ดแล้ว แต่ไม่มี it() ในรอบนี้

  • Gold พอดีของ seed จริง: Portrait unique = 4, Wide = 5, Visionary = 4 (มีแบบจำลอง 2/3/4 บน LENS-A/B/C ไม่ได้ยิงพูล SKU เต็มจาก seed)
  • SEL35F14GM คู่กับ SEL35F14GM/QSYX นับเป็นสอง unique ใน min_count — พฤติกรรมโค้ดยังไม่ถูกล็อกด้วยเทส
  • isActive = false และ now ก่อน activeFrom
  • registeredAt ว่าง / วันที่ parse ไม่ได้ → ไม่นับ
  • The Magnifier, Wide Architect, The Visionary ตามรายการ SKU ใน seed (มี Trinity / All Rounder / F2 / any-1 แทน)
  • Product Badge ที่ 0 serial บน buildBadgeExperience (locked โดยตรง) — มีแต่ของ engine no-badge เมื่อ products ว่าง
  • requiredCount ≤ 0 ให้ progress 100
ชุดนี้พิสูจน์เครื่องคำนวณและตัวจับคู่ SKU ไม่ได้พิสูจน์ว่า MySQL UAT มีกฎเวอร์ชัน 2026-07-24-product-urls-001 ตรงกับ seed
