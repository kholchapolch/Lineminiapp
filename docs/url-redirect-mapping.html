URL & Redirect Mapping

Source URL, Destination URL, Parameter และเงื่อนไข Redirect (HTTP 307/Next redirect หรือ client replace)

Middleware (ทุก request ที่ไม่ใช่ api/_next)

Source Destination พารามิเตอร์ เงื่อนไข
/ /th/my-badges คง query เดิมของ nextUrl เสมอ
/badge, /badge/ /th/my-badges คง query เสมอ
/my-badges และ subpath /th/my-badges… คง query ไม่มี prefix locale
/entry และ subpath /th/entry… คง query ไม่มี prefix locale
path ที่ segment แรกไม่ใช่ th/en ไม่ redirect — ตั้ง header x-locale=th แล้ว next()

หน้าแอป

Source Destination พารามิเตอร์ที่อ่าน/ส่ง เงื่อนไข
/{locale}/entry /{locale}/badges?entryError=missing-source entryError ไม่มีทั้ง Origin และ Referer
/{locale}/entry /{locale}/badges?entryError=blocked-source entryError Origin หรือ Referer ไม่อยู่ใน allow list
/{locale}/entry /{locale}/badges?entryError=missingLineSession entryError guard ผ่าน แต่ไม่มีคุกกี้เซสชัน
/{locale}/entry /{locale}/badges — guard ผ่าน และมีเซสชัน
/{locale}/badges?mock=1 /api/mock-session?locale=&sku= mock, sku (ซ้ำได้), locale APP_ENV=local และ Sony mock
/api/mock-session /{locale}/my-badges locale (ไม่ใช่ th/en → ใช้ th), sku อย่างน้อยหนึ่ง local+mock · ตั้งคุกกี้เซสชันจาก SKU
/api/mock-session JSON 400 MISSING_SKU — ไม่มี sku
/api/mock-session JSON 404 NOT_FOUND — ไม่ใช่ local+mock
/{locale}/badges /{locale}/my-badges — local + Sony mock (ไม่ใช่ debug=1)
/{locale}/badges client router.replace(my-badges) อาจมี entryError production line-session และ LIFF สำเร็จ ถ้ามี entryError จะไม่ replace
/{locale}/badges?debug=1 ไม่ redirect debug, lineuuid (วินิจฉัย) โหมด diagnostic
Query ที่หน้าบ้านใช้เอง: lineuuid ถูกเติมจากไคลเอนต์ตอนเรียก /api/my-* ไม่ใช่ redirect ของเซิร์ฟเวอร์
