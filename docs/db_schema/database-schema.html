ภาพรวมฐานข้อมูล (Database overview)

ชนิดฐานข้อมูล MySQL InnoDB (relational tables) BOOLEAN เก็บเป็น TINYINT(1)
สิ่งที่เก็บ การตั้งค่าเหรียญ (rules, groups, thresholds, conditions), ค่าคอนฟิกแอป และ log สรุปการคำนวณ
สิ่งที่ไม่เก็บ สินค้าที่ลูกค้ามี (Sony API), LINE session, และผลลัพธ์ชั้นเหรียญในเบราว์เซอร์
รายการตาราง (Table inventory)
ตาราง (Table) หน้าที่ (Purpose) PK
app_config ค่าคอนฟิกระดับแอปแบบ key/value key
badge_display_groups กลุ่มแสดงผลบนชั้นเหรียญ group_code
badge_rules ตัวตนเหรียญ หน้าต่างวันที่ และสถานะกฎ id
badge_rule_thresholds ระดับปลดล็อกและรูปภาพ id
badge_rule_conditions เงื่อนไข Eligible Product / SKU id
badge_calculation_logs log สรุปการคำนวณ ไม่ผูก FK กับกฎ id
Required = NOT NULL ต้องมีค่าตอน insert Optional = อนุญาต NULL Default ที่ว่างหมายถึงต้องใส่ค่าเอง ยกเว้นคอลัมน์ที่ระบบสร้างให้ เช่น AUTO_INCREMENT

app_config

ตารางอิสระ เก็บค่าคอนฟิก เช่นเวอร์ชันกฎ ไม่มี foreign key

Fields
Field Data type Required / Optional Default Keys คำอธิบาย
key VARCHAR(100) Required — PK ชื่อค่าคอนฟิก
value TEXT Required — ค่าที่เก็บ

แถวที่ seed ใส่: badge_rules_version, campaign_name, support_message

badge_display_groups

กลุ่มบนชั้นเหรียญ เช่น Full Frame Camera หรือ Quest Badge

Fields
Field Data type Required / Optional Default Keys / Check คำอธิบาย
group_code VARCHAR(120) Required — PK รหัสกลุ่มคงที่ เช่น prime-lens
badge_type VARCHAR(40) Required — CHECK product | quest ประเภทกลุ่ม
display_name VARCHAR(255) Required — ชื่อกลุ่มที่แสดง
sort_order INT Required 0 ลำดับแสดงกลุ่ม
is_active BOOLEAN Required TRUE กลุ่มนี้ยังใช้แสดงหรือไม่

badge_rules

ตารางกลางของเหรียญ ลูกมี thresholds และ conditions

Fields
Field Data type Required / Optional Default Keys / Check คำอธิบาย

badge_code VARCHAR(120) Required — UNIQUE รหัสคงที่ เช่น product-sel2470gm2

badge_rule_thresholds

ลูกของ badge_rules หนึ่งกฎมีได้หลายระดับ ลบกฎแล้วลบระดับตาม (CASCADE)

Fields
Field Data type Required / Optional Default Keys / Check คำอธิบาย
id INT Required AUTO_INCREMENT PK รหัสภายในของระดับ
badge_rule_id INT Required — FK → badge_rules.id ON DELETE CASCADE กฎเจ้าของระดับนี้
level VARCHAR(80) Required — UNIQUE ร่วมกับ badge_rule_id รหัสระดับ เช่น bronze, achievement
display_name VARCHAR(255) Required — ชื่อระดับที่แสดง
required_count INT Required — CHECK ≥ 0 matched count ที่ต้องถึงเพื่อปลดล็อก
achieved_image_url TEXT Optional NULL รูปสีเมื่อปลดล็อก
locked_image_url TEXT Optional NULL รูปตอนยังไม่ปลดล็อก
share_image_url TEXT Optional NULL รูปแชร์ / OG
sort_order INT Required 0 index ร่วมกับ badge_rule_id ลำดับแสดงระดับ

badge_rule_conditions

ลูกของ badge_rules เก็บ Eligible Product เป็น JSON ลบกฎแล้วลบเงื่อนไขตาม (CASCADE)

Fields
Field Data type Required / Optional Default Keys / Check คำอธิบาย
id INT Required AUTO_INCREMENT PK รหัสภายในของเงื่อนไข
badge_rule_id INT Required — FK → badge_rules.id ON DELETE CASCADE กฎเจ้าของเงื่อนไขนี้
condition_label VARCHAR(255) Required — UNIQUE ร่วมกับ badge_rule_id ป้ายอ่านใน SQL / debug
match_type VARCHAR(40) Required — CHECK any | all | min_count วิธีนับ SKU ใน list
required_count INT Required 1 CHECK ≥ 0 จำนวนที่ต้องมีในเงื่อนไขนี้ ถ้า all ระบบใช้ความยาวของ SKU list
sony_skus JSON Required — รายการ Eligible Product เช่น ["SEL2870GM","SEL50150GM"]

Index: idx_badge_rule_conditions_rule (badge_rule_id)

badge_calculation_logs

ตารางปฏิบัติการ ไม่มี FK ไปยังกฎเหรียญ เก็บ hash ของ LINE user id ไม่เก็บค่าดิบ

Fields
Field Data type Required / Optional Default Keys / Check คำอธิบาย
id INT Required AUTO_INCREMENT PK รหัสรายการ log
customer_line_uuid_hash VARCHAR(128) Required — hash ของ LINE user id
source_sku_count INT Required — CHECK ≥ 0 จำนวน SKU ต้นทางจาก Sony API
matched_sku_count INT Required — CHECK ≥ 0 จำนวน SKU ที่ match กฎ
earned_badges_json JSON Required — สรุปเหรียญที่ได้
error_code VARCHAR(120) Optional NULL รหัสข้อผิดพลาดถ้าคำนวณไม่สำเร็จ
error_message TEXT Optional NULL ข้อความข้อผิดพลาด
created_at TIMESTAMP Required CURRENT_TIMESTAMP index DESC เวลาที่บันทึก
