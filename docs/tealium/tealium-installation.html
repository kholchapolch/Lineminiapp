ขอบเขต

สคริปต์ Tealium ถูกใส่เฉพาะหน้า Home ของ Digital Badge ซึ่งคือ /{locale}/my-badges ทั้งภาษาไทยและอังกฤษ

หน้าที่ติดตั้ง
URL ติดตั้ง Tealium
/th/my-badges ใช่
/en/my-badges ใช่
หน้าอื่น เช่น My Missions, My Products, badge detail, share, portal ไม่ติดตั้ง

แอปไม่ได้เพิ่ม page-view tracking หรือ click tracking ของปุ่มเอง สคริปต์ที่มีคือชุดติดตั้ง Tealium ตามที่ Sony กำหนดเท่านั้น

Middleware ใส่ request header x-pathname แล้ว root layout ใช้ isDigitalBadgeHomePath() ตัดสินใจว่าจะเรนเดอร์สคริปต์หรือไม่ การเปิดหน้าอื่นแบบเต็มหน้าจึงไม่มีแท็กเหล่านี้ใน HTML

Data layer

Tealium เรียก window.buildSonyDataLayer() ฟังก์ชันอ่าน URL ปัจจุบันตอนถูกเรียก แล้วคืนอ็อบเจกต์ sony.digitalData

sony.digitalData.page
ฟิลด์ ค่าบนหน้า Home ที่มา
name home path my-badges
country TH ค่าคงที่ของ Mini App นี้
language th หรือ en segment แรกของ path
pageTemplate digital-badge ค่าคงที่
section line ค่าคงที่
currency THB ค่าคงที่

ตัวอย่างผลลัพธ์บน /th/my-badges เมื่อยังไม่ได้ล็อกอิน

{
  "digitalData": {
    "page": {
      "name": "home",
      "country": "TH",
      "language": "th",
      "pageTemplate": "digital-badge",
      "section": "line",
      "currency": "THB"
    },
    "user": { "id": "" }
  }
}

utag_data.website_platform เป็น "regional:marketing" คนละอ็อบเจกต์กับ sony.digitalData

User ID

sony.digitalData.user.id คือ My Sony Member ID ของ Mini App นี้ และใช้ LINE UUID ของผู้ใช้ที่ล็อกอินผ่าน LINE

ค่า user.id
สถานะ ค่า
ล็อกอินผ่าน LINE แล้ว LINE UUID เช่น Uxxxxxxxx
ยังไม่ได้ล็อกอิน ""

ลำดับการอ่านค่า

  1. ถ้าหน้า Home ตั้ง window.__sonyMemberId แล้ว ใช้ค่านั้น ค่าว่างหมายถึงยังไม่ได้ล็อกอิน และจะไม่ไปอ่านค่าเก่าต่อ
  2. ถ้ายังไม่ได้ตั้งค่า ฟังก์ชันอ่าน sessionStorage คีย์ sony_line_uuid ซึ่งเป็น LINE UUID ที่เซสชัน LINE เก็บไว้

หน้า Home ตั้ง window.__sonyMemberId จาก lineUuid ของ LINE session หลังสถานะล็อกอินนิ่งแล้ว

วิธีตรวจ

  1. เปิด /th/my-badges แล้วดู View Source
  2. ใน <head> ต้องเจอ utag-data แล้ว utag-sync แล้ว sony-data-layer
  3. สคริปต์แรกใน <body> ต้องเป็น utag-loader
  4. บน production URL ของ sync และ async ต้องมี /prod/ บน staging และ localhost ต้องมี /qa/
  5. ในคอนโซลเรียก buildSonyDataLayer() แล้วตรวจ digitalData.page และ digitalData.user.id
  6. เปิด /th/my-missions แบบเต็มหน้า ต้องไม่พบ utag.sync.js หรือ buildSonyDataLayer
  7. ใน Network tab ไฟล์ utag.sync.js และ utag.js ต้องตอบสำเร็จ

ข้อจำกัด

ข้อผิดพลาด window.SonyAnalytics is not a constructor ไม่ได้มาจากโค้ด Mini App แท็กในคอนเทนเนอร์ Tealium พยายามสร้าง SonyAnalytics ซึ่งปกติถูกประกาศโดย /campaign/GLOBAL/gwx/hook.js ของเว็บ Sony path นี้ไม่มีบน Mini App จึงตอบ 404

คอนเทนเนอร์ Tealium อาจยิงแท็กของตัวเองหลัง utag.js โหลด แอปไม่ได้เพิ่ม event ของการคลิกปุ่มหรือการเปลี่ยนหน้า การปิดแท็ก page หรือ CTA ต้องทำใน Tealium ของ Sony

ถ้าผู้ใช้เปิดหน้า Home แล้วเปลี่ยนไปหน้าอื่นแบบ client-side สคริปต์ที่โหลดไปแล้วจะยังอยู่ในเอกสารนั้น การเปิดหน้าอื่นโดยตรงจะไม่มีสคริปต์ Tealium
