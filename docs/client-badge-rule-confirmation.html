Sony Digital Badge Rule Understanding

เอกสารนี้สรุปความเข้าใจของทีมต่อข้อมูล Badge rules จาก Excel ของลูกค้า เพื่อใช้ยืนยัน logic ก่อนนำไปตั้งค่าในฐานข้อมูลและทดสอบกับ Sony API จริง

Quest Badge rules Case-insensitive SKU matching Database-configured rules No schema change required

Summary For Confirmation

  • ถ้า Excel ระบุแค่รายชื่อ SKU โดยไม่มีเงื่อนไขอื่น ทีมจะตีความว่า “มีสินค้าใดสินค้าหนึ่งใน list ก็ได้รับ Badge”
  • ระบบจะ match SKU แบบไม่สนตัวพิมพ์เล็ก/ใหญ่ แต่จะเก็บข้อความ SKU ตามที่ลูกค้าส่งมาเพื่อให้อ่านเทียบกับ Excel ได้ง่าย
  • Trinity Master จะต้องมีสินค้าอย่างน้อย 1 ชิ้นจากแต่ละกลุ่ม: 16-35 GM, 24-70 GM, และ 70-200 GM
  • All Rounder จะต้องมีสินค้า 3 รุ่นจากทั้งหมด 4 รุ่นที่ระบุ ไม่จำเป็นต้องครบทั้ง 4 รุ่น
  • ถ้า SKU จาก Sony API จริงไม่ตรงกับ Excel ต้องยืนยันว่าจะใช้ SKU จาก API เป็น source of truth หรือเพิ่ม mapping ภายหลัง

Implementation Note

Rules above will be stored in database tables, not hard-coded in the calculation logic. The application calculates Badge achievement from Sony API owned-product JSON by matching SKU lists in badge_rule_conditions and progress thresholds in badge_rule_thresholds.

ก่อน production ควรยืนยันตัวอย่าง response จาก Sony API จริงว่า field ที่ใช้เป็น SKU ตรงกับรหัสใน Excel หรือจำเป็นต้องทำ alias/mapping เพิ่ม
