  • Mobile-first Product Center

  • Product Card แสดง model, serial, warranty
  • CTA แบบกลุ่มต่อสินค้า
  • Content carousel ใต้ CTA

  • เพิ่ม Demo Control แยกจากหน้าลูกค้า

  • เพิ่ม state ที่ slide แสดงไม่ครบ เช่น API error และ no mapping
  • ทำ register page ด้วย typed dynamic blocks
  • ตัด Notification Page ออกจาก prototype เพราะไม่อยู่ใน current brief
  • ไม่แตะ component, CSS หรือ business logic ของ Badge

Screen anatomy

เหตุผลของแต่ละส่วนในหน้า

1 · Header/Profile ยืนยัน context ว่าเป็น Product Center ของสมาชิกคนใด
2 · Search ช่วยเมื่อผู้ใช้มีผลิตภัณฑ์หลายรายการ
3 · Product summary model, serial, warranty และสถานะ
4 · CTA mapping action ที่ต่างกันตาม product/category
5 · Content carousel firmware, tips และ highlight ที่เกี่ยวข้อง
6 · Bottom navigation Home, Register Product และ Demo cases
1
แยกข้อมูลประจำสินค้าออกจาก content ข้อมูล model/warranty มาจาก API; CTA/article/carousel มาจาก mapping
2
CTA เปิด Article overlay ใช้ action key เดียวกันเพื่อดึงชุดบทความ ไม่ link-out จาก CTA โดยตรง
3
Carousel แยกต่อ product ทดสอบลำดับและ content fallback โดยไม่ปนกันระหว่างสินค้า
4
Demo control อยู่นอกกรอบมือถือ Reviewer เห็น input/state ชัด โดยไม่ทำให้เข้าใจผิดว่าเป็น client UI
5
Layout เรียบตาม wireframe เน้น hierarchy, overflow และ behavior; ยังไม่ล็อกสี/spacing/visual identity

Dynamic content

ทำไมไม่จบที่ bullet

Register Product content ใช้ typed block renderer. Excel ปัจจุบัน map bullet เป็น check_list แต่ schema/UI รองรับ content ชนิดอื่นโดยไม่เปลี่ยน table

หัวข้อheading
ข้อความparagraph
รายการcheck_list
รูปภาพimage
ปุ่มลิงก์link_button
Prototype ไม่รองรับ raw HTML หรือ arbitrary component. Production importer ต้อง validate block type และ URL ก่อนบันทึก

What remains

สิ่งที่ prototype ยังไม่ทำ

  • ยังไม่เรียก My Sony API จริง
  • ยังไม่ใช้ LINE UUID จริงหรือ signed session
  • ยังไม่อ่าน Excel/import database
  • ยังไม่ใช้ 2-table production schema
  • ยังไม่ใช่ final UX/UI หรือ Sony visual guideline
  • ยังไม่ล็อก copy, image และ external URLs
  • ยังไม่ทำ notification feature
  • ยังไม่พร้อม deploy production
